# Coffee Shop Website
A responsive coffee shop website developed as a Web Programming course project using HTML5, CSS3, Bootstrap 5, JavaScript, and PHP.

## Features
- Responsive web design
- Semantic HTML structure
- Product catalog display
- Interactive user interface with JavaScript
- Bootstrap 5 components and layouts
- Basic PHP implementation

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript
- PHP
- XAMPP
- phpMyAdmin

## Project Status
This project currently focuses on front-end development and basic PHP implementation. A MySQL database has been prepared through phpMyAdmin as part of the learning process, while database connectivity and integration will be implemented in the next stage of the course.

## Learning Outcomes
Through this project, I practiced:
- Building responsive web pages
- Applying semantic HTML
- Styling with CSS and Bootstrap
- Creating interactive features with JavaScript
- Understanding PHP fundamentals
- Preparing database structures using phpMyAdmin
- Managing projects with Git and GitHub
